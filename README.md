# ZlpApps Facebook Agent - v1
Mac Terminal: `python3 -m venv .venv` ardından `source .venv/bin/activate`, `pip install -r requirements.txt`, `cp .env.example .env`, `open -e .env`. Anahtarları yalnız yerel .env dosyasına girin. `python agent.py --list-models` ile hesabınızın Pro model ID'sini bulun ve GEMINI_MODEL alanına yazın (models/ öneki kullanılabilir). apps.json içindeki facts ve links alanlarını gerçek uygulama özellikleri ve mağaza URL'leri ile doldurun. `python agent.py` yalnız önizleme yapar. 
Render: özel GitHub reposuna .env hariç dosyaları yükleyin. Üç Cron Job oluşturun: `0 6 * * 1`, `0 9 * * 3`, `0 15 * * 5` (UTC). Build: `pip install -r requirements.txt`; Command: `python agent.py` (test) veya `python agent.py --publish` (canlı). Her servise gerekli ortam değişkenlerini girin; canlı için AUTO_PUBLISH=true. Önce test gönderisinin başka bir kullanıcıdan görünürlüğünü doğrulayın. Her cron için manuel yayın komutunu aynı anda tetiklemeyin. Facebook geçmişi üzerinden aynı gün tekrarı azaltır, ancak atomik yayın garantisi yoktur. v1 sadece metin; görsel, dashboard, kalıcı kayıt ve alarm henüz yok. Token veri erişim süresini takip edin. API çağrıları ücretli olabilir.
